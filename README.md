# Cloak - Compose with Control

Cloak provides a minimal set of bindings to support compose on various desktop sessions, via GLFW. 
The purpose of this library is to enable rendering via MPV with OpenGL for Compose Desktop Applications.

For a compatible MPV library see zt64/mpv-kt [PR #85](https://github.com/zt64/mpv-kt/pull/85)


> [!WARNING]  
> This code is highly experimental, and currently in rapid prototyping.
